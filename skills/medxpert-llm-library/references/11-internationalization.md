## MedXpert-五补七、国际化：多语言图书馆与跨语言 RAG

> **国际化不是"以后再说"，是国际业务/国际读者的刚需**——医疗器械出口要啃 FDA/CE/MDR 英文文件，国际粉丝要看英文内容，小语种客户要能读到母语。**一套图书馆，装下全世界的知识，回答全世界的提问。**

### 1. 多语言图书馆组织（目录怎么摆）

**方案 A：语言分目录（推荐，清晰）**
```
my-library/
  01-法规/
    zh/               # 中文法规
      GMP-2025.md
    en/               # 英文法规
      FDA-21-CFR-820.md
      EU-MDR-2017-745.md
  02-产品/
    zh/  en/  de/
```

**方案 B：语言后缀（适合小库）**
```
GMP-2025-zh.md
GMP-2025-en.md
GMP-2025-de.md
```

**元信息加语言字段**：
```markdown
---
title: EU MDR 2017/745 解读
lang: en              # 语言标识（ISO 639-1）
original_lang: en     # 原文语言
translated_from: zh   # 从哪翻译的（如有）
---
```

> **多语言命名规范**：文件名统一 `主题-语言.md`（如 `MDR-2017-en.md`），AI 和人都能一眼看懂。

### 2. 翻译流程（本地模型搞定大部分）

| 场景 | 用谁翻译 | 质量 |
|------|---------|------|
| 中 ↔ 英（法规/文档） | **Qwen2.5:7B** | 良好，术语需人工核对 |
| 英 → 小语种（德/法/西等） | Qwen2.5:7B（先英再目标）或云端 API | 可读，专业术语要校对 |
| 关键法规条款 | 人工 + 模型辅助 | **必须人工终审**（法规错译后果严重） |

**翻译质量三原则**：
1. **法规条款人工终审**：翻译版仅供快速理解，正式使用以原文为准
2. **建立术语库**：公司名/产品名/法规术语统一翻译（`glossary.md`），模型翻译前先喂术语表
3. **双语对照存储**：原文保留（`en/`），翻译存 `zh/`，可追溯

### 3. 跨语言 RAG（关键技术：问中文能搜英文）

**核心问题**：用户用中文问，知识库里有英文原文（如 FDA 文件），怎么答？

**解法：多语言 Embedding**（这是关键）：
| Embedding 模型 | 语言支持 | 场景 |
|---------------|---------|------|
| **bge-m3** | **100+ 语言，跨语言检索强** | **首选**（中文提问 → 检索英文文档） |
| multilingual-e5-large | 100+ 语言 | 备选 |
| LaBSE | 100+ 语言 | 备选 |
| nomic-embed-text | 中英尚可 | 纯中文场景够用 |

**跨语言 RAG 流程**：
```
用户提问（中文）→ 多语言向量化（bge-m3）→ 检索中英文文档片段
→ 拼接（含原文语言）→ Qwen2.5:7B 用中文回答 + 标注来源语言
```

**语言路由（进阶）**：
- 检测问题语言 → 优先检索同语言文档，再补充其他语言
- 回答语言跟随问题语言（用户问中文答中文，问英文答英文）
- 引用时标注来源语言："（来源：FDA-21-CFR-820.md，英文原文）"

### 五补七扩展：小语种专项（全球市场全覆盖）

> **小语种 = 你的差异化竞争力。** 主流语种（中/英）大家都做，**小语种（德/法/西/葡/俄/日/韩/泰/印尼/越/阿拉伯）做的人少、需求真实**——尤其医疗器械出口市场，客户母语是这些语言的占比很高。

**覆盖范围（按医疗器械出口市场优先级）**：

| 地区 | 语言 | 代表市场 | 法规体系 |
|------|------|---------|---------|
| 欧洲 | 德语 | 德国/奥地利/瑞士 | CE-MDR |
| 欧洲/非洲 | 法语 | 法国/北非/西非 | CE-MDR |
| 拉美 | 西班牙语 | 墨西哥/南美 | 各国 ANVISA 类 |
| 巴西 | 葡萄牙语 | 巴西 | ANVISA |
| 俄语区 | 俄语 | 俄罗斯/中亚 | EAEU |
| 东亚 | 日语/韩语 | 日本/韩国 | PMDA/KFDA |
| 东南亚 | 泰/印尼/越语 | 东盟十国 | 各国注册 |
| 中东 | 阿拉伯语 | 海湾国家 | 各国注册 |

**小语种 RAG（关键：bge-m3 全支持）**：
- **bge-m3 支持 100+ 语言**——以上小语种全部覆盖，**跨语言检索开箱即用**（德语问、中文库、英文答都没问题）
- 小语种文档入库：语言分目录（`de/`、`fr/`、`es/`…）+ frontmatter `lang:` 字段
- 检索优化：小语种问题 → bge-m3 向量化 → 检索中/英/小语种文档 → 用问题语言回答 + 标注来源语言

**小语种翻译链路**：
```
中/英 原文 → Qwen2.5:7B 译成目标小语种（术语库 glossary.md 多语言化）
→ 人工/专业校对（法规条款必审）→ 双语对照存储（de/ 或 fr/ 子目录）
```
> 小语种翻译质量：Qwen 对主要小语种可读性好，专业术语靠术语库兜底；**法规条款一律人工终审**。

**小语种内容策略（变现/引流）**：
- 出口目标国法规解读（用当地语言写）——**竞争少、搜索易命中**（国际 SEO 蓝海）
- 小语种资料包/电子书（引流钩子）
- 国际 B 端服务：帮企业做目标国法规调研，用当地语言交付（高客单）
