# 医械法规标准知识库 · 会话载入技能

当你需要**不依赖 MCP** 地用 MedXpert-RA-Knowledge 知识库时，用本技能把"正确用法"装进上下文。若已配置 `medxpert-ortho-mcp`，优先用其标准 module 工具（见 medxpert-standards 专家包）。

## 一、先读图书馆地图
知识库根目录下的 `00-入口/llms.txt` 是给 AI 的地图，先读它了解结构，再按需读对应目录。核心层次：
- `01-法规原文/` L0 法规/标准/指南原文要点
- `02-结构化解读/` L1 条款拆解、国别对比
- `03-判定引擎/` L2 分类判定树/路径选择器/临床要求/发补风险/周期费用
- `04-案例库/` L3 脱敏项目复盘（当前 0 条真实实录）
- `05-交付物模板/` `06-术语与标准/` `07-变更雷达/` `08-时间轴/`

## 二、强制前置：版本判定（每次答法规题必做）
1. 确定**业务日期**（用户未指定 = 今天）
2. 读 `08-时间轴/法规效力时间轴.md`，找该日期落在哪一段
3. 只采用 `valid_from ≤ 业务日期 ≤ valid_to` 的知识
4. 距版本切换点 ≤90 天 → **必须同时提示新旧两版 + 切换日期**
5. 当前最高优先级：中国 GMP 2025 版（107 号公告）**2026-11-01 施行**，距今约 58 天，相关问题一律双版本提示

## 三、来源等级话术（不可违反）
- 官方原文 → 可直接给结论，标文号 + 施行日
- 官方解读 → 可给，注明"根据官方解读……"
- 行业整理 → 需加"建议与主管当局确认"
- 自建推导 → **不可直接给客户**，只说"我们的判断是……仅供内部参考"

判定引擎文档（03-判定引擎）多为 `行业整理/自建推导`、`confidence: low`，引用须声明；案例库 0 条真实实录，不得暗示有实证。

## 四、缺口标记（外循环）
遇到答不上/查不到/待核实 → 记入 `07-变更雷达/知识缺口队列.md` 对应分区（🔴阻塞/🟡待核实/⬜待建/📝草稿待确认）。**只标记，不编造、不自动改写**。

## 五、红线
- 🚫 禁止自动删除/改写知识（仅标记，人来拍板）
- 🚫 不确定的不答，库里无相关信息明说"未找到"
- 🚫 自建推导不冒充官方；案例脱敏占位不得反推
- 🚫 不构成合规意见，以官方现行版 + 有资质机构意见为准

## 六、自进化闭环（人工闸门）
知识库会自我进化：每周 `evolve_scan.py` 体检 → 抓新规/缺口 → 起草进暂存区 → 质检 → **人工批** → 提交升版。进化闭环脚本现位于 `ortho-mcp/evolution_loop.py`（与检测对接共用同一 MCP 仓库），严守"禁止自动改库"。
